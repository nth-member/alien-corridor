What this is

      
The Alien Corridor Support System is a GUI cockpit for the original 3PP-NOAH84 / MDQNM Clojure project (time machines, clocks, corridor matrices, data alphabets, gematria ciphers and clock enumerations across ~90 namespaces).

      
Preservation guarantee

      
Not one tittle of the original Clojure is altered. The complete original folder lives verbatim in engine/ (verified byte-identical to the source). This GUI is a separate process layer that loads those files unchanged with (require … :reload) — the same mechanism the author's Eclipse Counterclockwise REPL used — running on the project's own original stack: Clojure 1.7.0, clj-time 0.11.0, joda-time 2.8.2.

      
This edition: in your browser

      
This page runs the engine without a JVM or a server. The same unmodified .clj files are
      read by SCI, a Clojure interpreter in the page, which supplies only what the JVM supplied: java.util.Date,
      clj-time's from-long and local-now, and agents. The API this GUI calls is answered
      in the page itself. The JVM engine remains the reference; every module of both editions has been compared with it —
      see fidelity. What differs, and why: numbers print the JavaScript way
      (16800 for 16800.0; no exact ratios), a character literal such as \n is the
      one-letter string "n", clocks read this device's clock and re-seal whenever the page is reloaded,
      and each visitor's engine is their own.

      
Two editions

      
The source folder contains two distinct editions of the engine that differ in nearly every file: the primary mdqnm tree and the mdqnmshulammitebanksystem tree. Each runs in its own JVM so their same-named namespaces never contaminate each other. Launch with ./run.sh primary, ./run.sh bank, or ./run.sh both.

      
How to use

      
① Pick a module in the left manifest and LOAD it (top-level agents are created and sealed to the current instant, exactly as on a REPL load). ② Invoke its functions — enumerations print full reports; corridor matrices take a Y or Z argument. ③ DEREF agents to read sealed clock values. ④ Or drop to the Console for raw REPL access, with the author's recovered command history alongside.
